# Greenwood Public Library

A landing page for a made-up neighbourhood library, built while practicing Tailwind CSS. It's a single HTML file, so there's nothing to install or build.

## What's on the page

- Navbar with links to each section
- Hero with a short intro and two call-to-action buttons
- Quick stats (books, years of service, free Wi-Fi, sections)
- Six library sections: Fiction, Children's, Science, History, Periodicals and Digital
- A look inside the library's spaces
- "Why Greenwood" card grid
- About blurb
- Membership plans: Basic, Student and Family
- Member testimonial
- Visit info with opening hours
- Upcoming events
- Footer

## How to run it

1. Download or clone the project.
2. Make sure the `assets` folder sits next to `index.html` (it holds `hero.jpg`, `fiction.avif`, `2.jpg` and `3.avif`).
3. Open `index.html` in your browser.

You'll need an internet connection, since Tailwind loads from a CDN and some images come from Unsplash.

## Built with

- HTML
- Tailwind CSS v4 (browser CDN)
